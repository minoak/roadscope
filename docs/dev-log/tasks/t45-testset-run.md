# 지시서 t45: 시험 세트 99개 실행 (쓰기, 실행만, GPU 사용), t37 대체

## 배경
규칙은 개발 세트 `runs_in/nexar/` 30개를 보면서 고쳤다. 포트폴리오 숫자는 한 번도 보지 않은 시험 세트로 딱 한 번 낸다. 시험 세트는 `runs_in/testset/manifest.csv`(file, path; 영상은 HF 캐시)와 `labels.csv`. 사고/정상 반반, 조명 층화, 개발 세트, 증류 270개와 겹치지 않는다. 엔진은 t44+t48(차선 신뢰 2.0~4.0 m, 불신 구간 차선을 LDW, 수평선, H에서 제외) 반영 상태가 최종이다. 증류 학생 모델은 미적용.

## 할 것
1. **코드는 한 줄도 바꾸지 않는다.** 지금 엔진을 자동차 모드 기본값으로 99개 돌려 `runs_out/testset_t45/<file에서 .mp4 뺀 이름>/`에 저장한다. HF_HUB_OFFLINE=1, TRANSFORMERS_OFFLINE=1은 subprocess env로 넘긴다.
2. 시작 전에 엔진 파일(engine.py, geom_car.py, car_models.py)의 해시를 run_log.md 맨 위에 적는다.
3. run_log.md에 영상별 실행 시간, 종료 코드, 보정 결과(수평선 출처, 신뢰도, 실패 여부, 차선 신뢰 여부)를 남긴다. 실패하면 한 번 다시 돌리고, 그래도 실패하면 기록만 한다.
4. 결과를 보고 규칙을 고치거나 판정을 해석하지 마라. 시험 세트는 보는 순간 오염된다. 실행 상태(성공/실패, 시간)만 보고한다. 평가는 다음 작업(t46)이 한다.

## 범위
- 코드 수정 금지. 버그를 발견해도 고치지 말고 보고한다.
- 99개가 다 끝난 걸 확인한 뒤 보고한다. 백그라운드로 걸어두고 먼저 끝내지 마라. 4~5시간 걸린다.
- 같은 시간에 다른 GPU 작업은 없다. 커밋 금지.
