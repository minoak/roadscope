# 지시서 t34: t32 반영 엔진으로 Nexar 30개 재실행 (쓰기, GPU 사용 가능)

## 배경
t32에서 LDW에 차로 안 평소 위치 기준을 넣었고 CPU로 앞 15초만 확인했다. neg_01539는 왼쪽 LDW가 줄었지만 오른쪽이 3→8로 늘었다. 전체 효과는 30개를 다시 돌려야 안다. 민옥이 지금은 GPU를 써도 된다고 했다.

## 할 것
1. 코드는 바꾸지 않는다. t32 상태 그대로 30개 전부를 자동차 모드 기본값으로 돌려 `runs_out/nexar_t34/`에 저장한다. run_log.md에 영상별 실행 시간, 보정값, lane_baseline(b, 근거 수, 상한 여부)을 남긴다.
2. 끝나면 t29 대비 LDW 변화만 간단히 표로 낸다: 영상별 LDW 프레임(좌/우), 정상 영상 합계. 공식 평가는 Codex가 한다.
3. 실행 중 오류나 이상(GPU 메모리 부족 등)이 있으면 영상 단위로 다시 돌리고 기록한다.

## 범위
- 코드 수정 금지(실행만). 버그를 발견하면 고치지 말고 보고한다.
- 30개가 다 끝난 걸 확인한 뒤 보고한다. 백그라운드로 걸어두고 먼저 끝내지 마라.
- 같은 시간에 Codex가 web/ 쪽 화면 작업을 한다(GPU 안 씀). 포트 7861에 개발 모드 서버가 떠 있다. 건드리지 마라.
