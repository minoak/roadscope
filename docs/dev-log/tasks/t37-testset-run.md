# 지시서 t37: 시험 세트 99개 실행 (쓰기, 실행만, GPU 사용)

## 배경
지금까지 규칙은 `runs_in/nexar/`의 30개(개발 세트)를 보면서 고쳤다. 그래서 그 점수는 연습 문제 점수에 가깝다. 포트폴리오에 쓸 숫자는 한 번도 보지 않은 영상으로 낸다. 민옥이 개발 세트와 시험 세트를 나누기로 했다(`.orch/DECISIONS.md` 마지막 줄). 시험 세트는 `runs_in/testset/manifest.csv`(file, path; 영상은 HF 캐시)와 `labels.csv`에 있다. 사고/정상 반반, 조명 비율 층화, 개발 세트와 증류 학습용 270개와 겹치지 않는다.

## 할 것
1. **코드는 한 줄도 바꾸지 않는다.** 지금 엔진(t32 상태, 증류 학생 모델 미적용) 그대로 99개를 자동차 모드 기본값으로 돌려 `runs_out/testset_t37/<file 이름에서 .mp4 뺀 것>/`에 저장한다.
2. run_log.md에 영상별 실행 시간, 종료 코드, 보정 결과(수평선 출처와 신뢰도, 실패 여부)를 남긴다. 실패하면 한 번 다시 돌리고, 그래도 실패하면 기록만 한다.
3. 결과를 보고 규칙을 고치거나 판정을 해석하지 마라. 시험 세트는 보는 순간 오염된다. 실행 상태(성공/실패, 시간)만 보고한다. 평가는 Codex가 한다.

## 범위
- 코드 수정 금지. 버그를 발견해도 고치지 말고 보고한다.
- 99개가 다 끝난 걸 확인한 뒤 보고한다. 백그라운드로 걸어두고 먼저 끝내지 마라. 4~5시간 걸린다.
- 같은 시간에 다른 GPU 작업은 없다.
