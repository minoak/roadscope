# 지시서 t36: "내 차" 영역 증류 학습 (쓰기, GPU 사용)

## 배경
자동차 모드는 사전 점검에서 내 차 영역(보닛, 대시보드, A필러, 룸미러, 실내 반사)을 구한다. Mask2Former(Vistas Ego Vehicle + Car Mount) 5장 투표, YOLO 반복 검출, 정지 영역을 합친다. 너(t29)가 만든 코드다. Mask2Former가 CPU 2.6초/장이라 매 프레임에는 못 쓴다. 이걸 선생으로 써서 한 장만 보고 내 차 영역을 그리는 가벼운 모델을 학습한다. 포트폴리오에서 "모델 학습" 부분을 채우는 작업이기도 하다. 결정은 `.orch/DECISIONS.md` 마지막 두 줄.

## 데이터
- 학습용: `runs_in/distill/manifest.csv`의 Nexar 270개(영상은 HF 캐시 경로). 관리자가 받아 두었다. 영상 단위로 학습/검증을 나눈다(예: 240/30). 같은 영상의 프레임이 양쪽에 섞이면 안 된다.
- 시험용: `runs_in/nexar/`의 평가용 30개. 학습, 검증에 절대 쓰지 않는다. 이상치 3개(pos_00905, neg_01960, pos_00754)는 시험 결과에 따로 표시한다.

## 할 것
1. **정답 만들기 (`tools/distill/make_labels.py`):** 영상마다 엔진의 사전 점검 함수로 내 차 영역 마스크를 구한다(엔진과 같은 코드를 import해서 써라. 다시 짜지 마라). 카메라가 고정이라 영상 하나에 마스크 하나다. 영상마다 프레임 10~15장을 고루 뽑아 그 마스크를 정답으로 붙인다. 사전 점검이 실패했거나 근거가 약한 영상(예: 내 차 움직임 판정 실패, Mask2Former 투표 불안정)은 빼거나 표시한다. 빼는 기준과 개수를 보고한다.
2. **학습 (`tools/distill/train_ego.py`):** smp U-Net ResNet34, 출력은 "내 차" 이진 마스크. 입력 해상도, 증강(밝기, 대비, 약한 이동, 확대, 좌우 반전 여부), 손실(BCE+Dice 등), 에폭은 네가 정하고 근거를 적는다. 사전학습 인코더 가중치를 받을 수 있으면 써도 된다(받은 출처를 기록).
3. **평가 (`tools/distill/eval_ego.py`):**
   - 검증, 시험 세트에서 선생 마스크 대비 IoU(영상별, 전체 중앙값), 낮과 밤으로 나눠서
   - 한 장 처리 시간(GPU, CPU)
   - IoU가 가장 낮은 시험 영상 5개는 선생, 학생 마스크를 겹친 이미지를 `runs_out/distill/check/`에 남긴다. neg_01711(왼쪽 끝 실내 물체)과 pos_00413(하단 넓은 오검출 영역)은 꼭 포함한다. 관리자가 직접 본다.
   - 학생이 선생보다 나아 보이는 경우가 있으면(예: 선생이 놓친 실내를 학생이 잡음) 따로 적는다. 정답이 선생이라 IoU로는 안 드러나는 부분이다.
4. 엔진에는 아직 넣지 않는다. 넣을지는 결과를 보고 민옥이 정한다.

## 저장

- 학습 곡선(손실, 검증 IoU)을 PNG 하나로 남긴다.

## 범위
- engine.py, geom_car.py, car_models.py는 수정 금지(import만). 필요하면 보고해라.

- 학습과 평가가 다 끝난 걸 확인한 뒤 보고한다. 백그라운드로 걸어두고 먼저 끝내지 마라.
