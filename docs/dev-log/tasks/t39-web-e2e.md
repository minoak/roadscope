# 지시서 t39: 웹 실제 업로드 흐름 끝까지 확인 (쓰기, GPU 사용)

## 배경
t33, t35에서 웹 화면(web/)을 만들었고, 저장된 결과로만 확인했다. 업로드 → 엔진 → HUD 영상 → 결과 화면의 실제 흐름은 아직 한 번도 돌리지 않았다. 지금은 GPU를 써도 된다(다른 GPU 작업 없음).

## 할 것
1. 실제 모드 서버를 포트 7863으로 띄운다(7861은 관리자가 띄운 개발 모드 서버라 건드리지 않는다).
2. `runs_in/nexar/pos_00348.mp4`를 API(`POST /api/jobs`, vehicle=car)로 올리고, 끝날 때까지 상태를 조회한다. 단계와 진행률이 순서대로 바뀌는지 기록한다.
3. 끝나면 확인한다.
   - HUD 영상이 H.264로 재생 가능한지(ffprobe 등으로 코덱, 길이 확인), byte-range 요청이 되는지
   - 결과 요약이 같은 영상의 frames.jsonl과 맞는지
   - 결과 화면 HTML이 뜨는지(브라우저 자동화가 막히면 API와 정적 파일 응답까지만)
4. 오토바이 모드도 짧게 한 번: `runs_in/mixkit_pov_31974_720.mp4`, vehicle=moto.
5. 문제가 있으면 web/ 안에서 고친다. 엔진 쪽 문제면 고치지 말고 보고한다.
6. 끝나면 7863 서버를 내린다.
