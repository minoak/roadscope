# 지시서 t33: 서비스용 웹 화면 구현 (FastAPI + HTML 한 장) (쓰기)

## 배경
민옥이 MVP 화면을 서비스용 웹페이지로 다시 만들기로 했다(`.orch/DECISIONS.md` 2026-10-09 "MVP 화면은 서비스용 웹페이지로"). 시안은 Claude Design 캔버스로 만들었고 민옥이 확인했다. 시안 원본은 `.orch/design/`의 세 파일이다: `Main.dc.html`(업로드), `Analyzing.dc.html`(분석 중), `Result.dc.html`(결과). 캔버스 전용 형식(`<x-dc>`, `{{hole}}`, `<sc-for>`, 아래쪽 `class Component`)이지만, 레이아웃, 색, 글꼴, 문구는 그대로 옮기면 된다. 결과 화면의 동작(타임라인이나 경고 목록을 누르면 그 시점으로 이동, 신뢰 낮음 띠)도 시안 스크립트에 있다.

## 만들 것
1. **`web/server.py` (FastAPI):** 기존 `app.py`의 작업 처리(백그라운드 작업, 진행률, engine 호출, H.264 변환)를 가져와 쓴다. app.py는 지우거나 고치지 말고 공통 부분은 필요하면 새 모듈로 뽑아라(app.py가 계속 동작해야 한다).
   - `POST /api/jobs`: 영상 업로드 + 차량(car/moto). 작업 id를 돌려준다.
   - `GET /api/jobs/{id}`: 상태, 진행률, 단계(영상 확인 / 카메라 측정 / 장면 판정 / 결과 영상 만들기), 끝났으면 결과 요약.
   - 결과 요약은 frames.jsonl과 meta.json에서 만든다: 영상 길이, 등급 구간 목록(시작, 끝, 등급), 경고가 바뀐 순간 목록(시각, 등급, 사유 문장), 가장 높은 등급과 그 시각, 사유, 위험 이상 구간 수와 길이, 주의 구간 수와 합계, 카메라 측정값(수평선, 소실점 가로, 카메라 높이, 초점거리, 내 차 영역 %, 차로 안 평소 위치), 측정 신뢰도.
   - 측정 신뢰 낮음: 자동차 모드에서 영상 단위 보정이 실패한 경우(meta car_calib의 horizon_conf가 failed). 결정 기록의 이상치 기준이다.
   - 결과 파일 내려받기: HUD 영상(H.264 MP4), frames.jsonl, 타임라인 PNG.
2. **`web/static/index.html` (+ 필요하면 같은 폴더 css/js):** 시안 세 화면을 한 페이지에서 해시 주소로 바꾼다(`#/`, `#/job/<id>`). 분석 중 화면은 주기적으로 상태를 받아 갱신하고, 끝나면 결과 화면으로 넘어간다. 창을 닫았다가 같은 주소로 오면 이어서 보여야 한다. 빌드 도구 없이 바닐라 JS로 만든다. 결과 화면의 영상은 실제 `<video>`로 재생하고, 타임라인 구간과 경고 목록을 누르면 `currentTime`을 옮긴다. 재생 위치를 따라 타임라인 표시선과 현재 등급 표시도 움직인다.
3. **실행:** `run_web.bat`(기존 `run_app.bat`처럼 가상환경 python으로 서버 실행 + 브라우저 열기). 포트는 7861로 해서 기존 Gradio(7860)와 겹치지 않게 한다.
4. **개발용 결과 보기:** GPU 없이 화면을 확인할 수 있게, 이미 있는 결과 폴더(`runs_out/nexar_t29/<영상>/`)를 작업처럼 불러오는 개발용 경로를 둔다(예: `GET /dev/load?run=nexar_t29/pos_00348`). 화면에는 노출하지 않는다. HUD 영상이 없는 결과면 영상 자리에 안내 문구만 보여준다.

## 확인 (GPU 금지)
- 민옥이 이번에는 GPU를 쓰지 않길 원한다. 엔진 실제 실행은 하지 마라. 서버는 띄워서 개발용 경로로 결과 화면을 확인한다: pos_00348(사고, 보정 정상), neg_01711(정상, 실내 제외 많음), pos_00905(이상치, 측정 신뢰 낮음).
- 결과 요약 API의 숫자가 frames.jsonl과 맞는지 한 영상에 대해 직접 대조해 보고한다.
- 화면 폭 390px(휴대폰)에서도 깨지지 않는지 확인한다.
- 업로드부터 엔진 실행까지의 실제 흐름은 코드 경로만 점검하고, 실행 확인은 다음에 GPU를 쓸 때 한다고 보고에 적어라.

## 범위
- 수정 가능: `web/`(새 폴더), `run_web.bat`(새 파일), 공통 모듈이 필요하면 새 파일 하나. app.py는 동작이 바뀌지 않는 범위에서 import 정리만 허용.
- 금지: engine.py, geom_car.py, car_models.py, viz.py, `.orch/contracts/`. engine 실행과 GPU 사용 금지.
- FastAPI, uvicorn이 가상환경에 없으면 설치하지 말고 보고해라(관리자가 설치한다).
