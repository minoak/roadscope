# 지시서 t02: 실행 가능성 점검 (읽기, 명령 실행 가능)

## 목적
이 폴더는 블랙박스 영상으로 주행 위험도를 평가하는 프로젝트야. src/ 의 .py 파일들을 조합해서 MVP를 만들기 전에, 지금 이 컴퓨터에서 실제로 돌아갈 수 있는 상태인지 확인해줘.

## 확인할 것
1. requirements.txt 와 src/*.py 의 import 를 비교해서, 현재 Python 환경에 없는 패키지 목록
2. 각 src/*.py 를 `python -c "import ..."` 수준으로 불러봤을 때 되는지, 안 되면 에러 한 줄
3. 모델 가중치나 외부 파일이 필요한지. 필요하면 코드 어디에서 어떤 경로를 기대하는지, 그 파일이 이 폴더에 있는지
4. samples/ (images, masks, expected_outputs.json) 로 끝까지 한 번 돌려볼 수 있는 경로가 있는지. 있으면 어떤 함수 호출 순서인지

## 범위
- 패키지 설치 금지, 파일 수정 금지. 확인만.
- 루트의 큰 .ipynb (2~3MB) 는 열지 마.
- 오래 걸리는 추론이나 학습은 돌리지 마.
