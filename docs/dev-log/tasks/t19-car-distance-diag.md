# 지시서 t19: 자동차 모드 거리 붕괴 원인 진단 (읽기, 명령 실행 가능)

## 관찰 (관리자)
Nexar 자동차 영상 9개(car 모드) 결과 `runs_out/nexar/<파일명>/frames.jsonl`:
- 위험 이상(bin≥2) 프레임이 정상 영상에서도 31~63%. 사고 영상은 영상 시작(0~1초)부터 위험.
- 위험의 원인 경고: FCW L3 457, BSW L2 263, FCW L2 74, BSW L3 56.
- 경고 대상 객체의 거리 중앙값 0.7m (843건). 사유 문구 예: "정면 0.5m (화면 0%)", "좌측 근접 0.5m", "정면 0.5m (화면 2%)". 화면의 0~2% 를 차지하는 작은 박스가 0.5m 로 판정된다.
- 출처: yolo car 320, ghost car 207, yolo truck 92, yolo_lowconf 72 ...

## 할 것
엔진 코드(engine.py)와 결과 파일, 가능하면 `--dump-estimates` 로 영상 하나(예: neg_01960, 18초)를 다시 돌려서 원인을 찾아. 가상환경 Python 사용 가능, GPU 사용 가능 (다른 작업이 끝났는지 nvidia-smi 로 확인 후).
의심 지점: 거리 하한 0.5m 이 어디서 오는지(유령 외삽 하한, 두 성분 중 가까운 쪽 규칙, 카메라 높이 1.3m 적용, 보닛 띠, Depth Pro 초점 고정의 car 영상 영향), moto 모드에서는 왜 안 생기는지.
