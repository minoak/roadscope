# 지시서 t35: 웹 화면 다듬기 (쓰기, GPU 금지)

## 배경
t33에서 만든 웹 화면을 관리자가 브라우저로 확인했다. 데스크톱, 휴대폰 폭, 신뢰 낮음 띠는 정상이다. 고칠 점이 두 개 나왔다. 지금 Claude가 GPU로 Nexar 30개를 돌리는 중이라 엔진과 GPU는 쓰지 않는다.

## 할 것
1. **경고 목록의 깜빡임 묶기:** pos_00905처럼 등급이 프레임마다 주의↔위험을 오가면 목록이 지저분하다(`/dev/load?run=nexar_t29/pos_00905`). 목록과 요약 카드의 구간 수에서 0.5초 미만으로 끊겼다 이어지는 같은 방향의 변화는 하나로 묶는다. 묶을 때 더 높은 등급을 남긴다(위험, 치명은 놓치지 않는 쪽 원칙). 타임라인 색 띠와 frames.jsonl 원자료는 바꾸지 않는다. 화면 표시만의 처리라는 걸 web/README.md에 적는다. 묶는 기준 0.5초는 상수 하나로 둔다.
2. **개발 모드 실행 파일:** `run_web_dev.bat`을 만든다. 더블클릭하면 `run_web.bat --dev`와 같은 모드로 뜨고 브라우저에서 pos_00348 개발용 결과를 연다.
3. 바꾼 뒤 요약 API 숫자(위험 이상 구간 수, 주의 구간 수)가 어떻게 바뀌는지 pos_00348, pos_00905, neg_01711 세 개로 전후 표를 낸다.

## 범위
- 수정 가능: web/, run_web_dev.bat(새 파일). engine.py, geom_car.py, car_models.py, viz.py, app.py 금지.
- 7861 포트에 관리자가 띄운 개발 모드 서버가 있다. 확인이 필요하면 다른 포트(7862)로 따로 띄워라.
- 엔진 실행과 GPU 사용 금지.
