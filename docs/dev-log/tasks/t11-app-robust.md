# 지시서 t11: 화면 안정화 (쓰기)

## 배경
민옥이 app.py 를 실제로 써봤다.
1. OpenCV 로 저장된 FMP4(MPEG-4 Part 2) 영상은 Gradio 에서 "재생 가능한 비디오가 아니다"로 거부됐다. H.264 영상(mixkit)만 분석 가능했다.
2. 분석 중 브라우저에 ConnectionResetError [WinError 10054] 가 떴다. 엔진은 계속 돌았다. 분석 요청 하나가 몇 분씩 연결을 붙잡는 구조라 생기는 문제로 보인다.
3. "합성 예시 보기" 결과(mock)를 실제 결과로 착각했다. MOCK 표시가 있었지만 충분하지 않았다.

## 할 것
1. 업로드 영상을 분석 전에 H.264(yuv420p, mp4)로 변환해서 쓴다. 코덱이 이미 H.264 면 건너뛴다. FFmpeg 은 imageio_ffmpeg.get_ffmpeg_exe(). 변환 실패 시 사용자에게 한국어로 이유 표시.
2. 긴 분석을 요청 하나로 붙잡지 말고 백그라운드 작업으로 돌린 뒤, 화면은 진행률(engine.log 의 진행 줄 또는 frames.jsonl 줄 수 / 예상 프레임 수)을 주기적으로 받아오게. 브라우저 연결이 끊겼다 붙어도 결과를 다시 볼 수 있게 (작업 id 기준).
3. 합성 예시: 서비스 화면에서 기본으로 숨기거나 별도 탭/접힌 영역으로 분리. 보여줄 때는 결과 영역 전체에 MOCK 임이 분명히 보이게.

## 실행 관련
샌드박스에서 가상환경 Python 실행이 안 된다. tools/check_viz.py 에 위 1~3 확인 항목(FMP4 입력 변환, 작업 id 로 결과 재조회, mock 분리)을 추가해두면 관리자가 돌린다.

app.py, viz.py, tools/check_viz.py, tools/mock_frames.py 만. engine.py 와 스키마는 수정 금지. 지금 다른 실행자가 engine.py 를 고치고 있다 (차선 밟음 감지).
