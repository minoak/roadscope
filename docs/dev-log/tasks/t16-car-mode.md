# 지시서 t16: 자동차 블랙박스 모드 (쓰기, 작게)

## 목적
민옥 결정: 일반 자동차 블랙박스 영상으로도 테스트한다. lane_focus 의 바이크 관련 클래스(5 My bike, 6 Rider)를 무시하면 된다.

## 할 것
- `engine.py` 에 `--vehicle {moto,car}` (기본 moto). app.py 는 지금 이 옵션을 안 넘기므로 기본값은 기존과 같아야 한다.
- car 모드:
  - class 5, 6 을 ego 로 쓰지 않는다 (보닛을 바이크로 잡아도 무시).
  - ego 에 기대는 규칙: ego 오탐 제거, 2m 억제, 바이크 영역 lane 픽셀 제거, 차선 위 주행 판정, 마스크 보조 박스의 ego 제외 조건 → ego 없이 합리적으로 동작하게. 내 위치(ego_cx)는 화면 가로 중앙.
  - 화면 하단 보닛 영역은 영상마다 다르니, 하단 일정 비율(값은 네가 정해)을 검출, 차선에서 제외하는 옵션 `--hood-ratio`.
  - meta.json 에 vehicle 기록.
- moto 모드 결과는 t15 와 레코드가 같아야 한다 (mixkit, night 로 확인).

## 확인
moto 회귀 확인만. car 영상은 아직 없다 (관리자가 구하는 중).

## 범위
engine.py 만. 판정 기준, 스키마, viz.py, app.py 금지.
