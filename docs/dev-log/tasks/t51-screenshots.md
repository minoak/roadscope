## 배경
새 리포 README에 넣을 화면 캡처가 필요하다. 민옥 결정(DECISIONS.md 2026-10-10): Nexar 출처 표기, 번호판, 얼굴 흐림. 시험 세트(runs_in/testset, runs_out/testset_t45) 영상, 결과는 쓰지 않는다. 개발 세트(runs_out/nexar_t48) 결과만 쓴다.

## 만들 것
1. 웹 화면 3장 (1280×800 정도): 업로드 화면, 분석 중 화면, 결과 화면(HUD 영상 프레임 + 타임라인 + 요약).
   - web/ 서버를 이 작업용 포트(7865)로 띄우고, dev 모드(`/dev/load?run=...`)로 nexar_t48의 클립 하나를 불러 결과 화면을 만든다. 분석 중 화면은 실제 진행 상태가 어려우면 dev 모드에서 보여줄 수 있는 방법을 쓰고, 안 되면 건너뛰고 보고에 적는다.
   - 캡처는 설치된 도구로만: Python playwright가 있으면 그것, 없으면 Edge/Chrome 헤드리스 `--screenshot`. 새 패키지 설치 금지.
   - 끝나면 띄운 서버는 반드시 종료.
2. HUD 결과 프레임 4~6장: nexar_t48 결과 영상에서 위험(L2), 치명(L3), 주의, 안전이 잘 보이는 장면. 사고 클립 1~2개, 정상 클립 1개 이상, 낮/어두움 섞기. 클립 선택 이유를 한 줄씩.
3. 흐림 처리: 모든 이미지에서 사람 박스는 머리 부분, 차량 박스는 번호판이 있을 법한 하단 중앙을 가우시안 흐림. 흐림 전 원본은 저장하지 말고(혹은 _raw/ 폴더에 따로 두고 리포 제외 표시), 흐림 후 이미지만 결과로.
4. index.md: 파일별 설명, 출처(Nexar collision prediction, Nexar Open Data License), 어떤 클립의 몇 초인지, 흐림 처리 여부. 민옥이 직접 확인해야 할 이미지(번호판이 여전히 읽힐 수 있는 것 등) 표시.
