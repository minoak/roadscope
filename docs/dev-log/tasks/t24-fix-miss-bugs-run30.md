# 지시서 t24: 리뷰가 찾은 미탐 쪽 버그 4개 수정 후 Nexar 30개 실행 (쓰기)

## 배경
t22 실행 중에 Codex 리뷰(t23)가 위험을 낮추는 쪽으로 기우는 버그 4개를 찾았다. 그래서 관리자가 t22를 중간에 멈췄다(30개 중 5개 완료 시점). 리뷰 원문은 `.orch/runs/20261009-102720-codex-t23-review-car-geometry/report.md`에 있다. 줄 번호는 리뷰 시점 기준이라 지금과 다를 수 있다.

먼저 t22에서 하던 코드 변경(TTC를 판정에서 빼기, LDW 시간 보정 제거)이 끝까지 들어갔는지 확인해라. 덜 됐으면 마저 한다. `runs_out/nexar_t22/`는 버그가 있는 상태의 중간 결과라 쓰지 않는다.

## 고칠 것 (원칙: 위험, 치명은 미탐 억제가 우선)
1. **근접 상한 무시:** 차폭 거리가 있을 때도 보닛 경계에서 나온 근접 상한(hood_bound)과 비교해서 가까운 쪽을 쓴다. 리뷰 예시는 neg_01988 8.824초, 박스 [480,362,651,483]이다. 상한 4.88 m 대신 6.5 m를 써서 L2가 L1로 내려갔다.
2. **보정 실패와 잘린 박스가 겹칠 때:** 거리를 못 구해도 FCW 판정을 끝내지 않는다. 면적 기반 판정(화면 비율)까지는 도달해야 한다. 화면 54%를 덮는 박스가 L0이 되면 안 된다.
3. **보닛 추정 실패 시 객체 삭제:** 보닛 추정이 실패하면 기본 하단 12%를 확정 보닛처럼 써서 박스를 지우지 않는다. 실패했을 때는 박스를 지우지 않는 쪽으로 처리한다(오탐이 늘더라도 미탐보다 낫다).
4. **소실점 좌표 섞임:** 수평선 후보를 거른 뒤에 x와 y를 같은 출처에서 함께 고른다. 탈락한 FOE의 x와 차선 VP의 y가 섞이지 않게 한다.

각 버그는 리뷰에 적힌 입력으로 고치기 전과 후를 재현해서 보고한다.
