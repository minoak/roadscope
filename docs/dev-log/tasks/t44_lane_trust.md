# t44: 차선 신뢰 범위 2.0~4.0 m: 범위 밖이면 차선을 LDW, 수평선, 카메라 높이에서 모두 뺀다 (write)

## 배경
- t41: LDW 방식 비교. t43(Codex): 차선 오검출이 수평선/카메라 높이를 통해 거리, FCW를 틀어지게 함. pos_00602(영점 차로폭 1.78 m)에서 차선 H 1.408 m가 쓰여 바닥 거리/폭 거리 0.55배, 차선 제외 시 FCW 레벨 162프레임 변화. pos_00411(5.59 m) 수평선 24 px, FCW 69프레임. 코드 경로: C53→E1910→G846(FOE→차선→회귀 단독 선택), G915(H 차량, 차선 평균/선택).
- 민옥 결정(2026-10-10): 차로폭 정상 범위 3.0±1.0 m(2.0~4.0 m). 범위 밖이면 LDW 경고 없이 "차선 신뢰 낮음" 표시만. 그리고 그 구간은 차선을 수평선, 소실점, 카메라 높이 계산에서도 빼고 FOE와 앞차만 쓴다.

## 할 일 (자동차 모드, 엔진 기본 동작으로)
1. 차선 신뢰 판정: 영점 y_ref 차로폭이 2.0~4.0 m 안이면 신뢰, 밖이거나 영점 실패면 불신. 상수로 두고 이름을 분명히.
2. 불신 구간: LDW는 측정 불가(사유 "차선 신뢰 낮음"), 경고 없음.
3. 불신 구간: 차선 교점 후보를 수평선, 소실점 선택에서 제외, 차선 기반 H를 H 추정에서 제외. FOE, 차량 회귀, 차량 H만 사용. 모두 없으면 기존 기본값 경로 + 신뢰 낮음 표시.
4. 순환 문제 주의: 차로폭(m)은 H와 수평선에 의존하는데 그 H, 수평선이 차선에서 왔을 수 있다. 신뢰 판정에 쓰는 차로폭을 어떤 H, 수평선으로 계산할지 정하고(예: 차선 없이 구한 H, 수평선으로 다시 계산, 없으면 픽셀 비율이나 불신 처리), 판단 근거를 보고에 쓴다.
5. meta에 구간별 lane_trust(true/false, 사유, 계산에 쓴 차로폭)를 남긴다. 키 이름은 보고에.
6. 기존 `--ldw-variant`는 남겨도 되지만 기본값이 새 동작이어야 한다.
