# 지시서 t26: 보정 안전장치와 침범 기준 조정 후 30개 재실행 (쓰기)

## 배경
t24 결과를 Codex가 평가했다(t25, `runs_out/nexar_t24/eval.md`). 사고 20개 중 미탐 2개, 사고 밖 위험 이상 25.5%, 정상 영상 주의 38%. 오경보는 보정 신뢰도 low 영상 9개에 몰려 있고(57%, high는 13%), 주의는 대부분 차선 침범에서 나왔다. 민옥이 정한 내용은 `.orch/DECISIONS.md` 마지막 두 줄이다.

## 할 것 (자동차 모드만)
1. **소실점 x 범위:** 영상 단위 보정에서 소실점 x를 화면 폭 20~80% 안으로 제한한다. 범위 밖이면 그 후보를 버리고 다른 출처를 쓰거나, 없으면 화면 중앙에 신뢰도 low로 둔다. pos_00754(x = −12 px)로 확인한다.
2. **신뢰도 low일 때 근접 상한 끄기:** 보정 신뢰도가 low인 구간에서는 hood_bound를 거리 후보로 쓰지 않는다. 바닥 위치와 차폭 거리만 쓴다. 둘 다 없으면 t24에서 넣은 면적 기준(area_no_distance)은 그대로 둔다. neg_01711, pos_00602로 확인한다.
3. **차선 침범 기준:** 박스 바닥 안쪽 끝의 |X|가 1.25 m 미만일 때만 침범으로 본다(지금은 1.5 m). 바깥쪽 조건(>1.75 m)은 그대로 둔다.
4. 미탐 2건(pos_00004, pos_00877)은 고치려 하지 말고, 바뀐 뒤에도 같은지만 보고한다. FCW 거리 기준 3/5/10 m는 바꾸지 않는다.
