## 관리자 판단 필요

**1. 기존 HUD 유지 범위**

노트북 HUD는 위험등급, FCW, LDW, BSW, HEAD 활성 경고와 사유, 객체 박스, 차선, 편향 표시, 위험구역, 측면구역, 정면, 좌, 우 거리, 초점거리, 보정 여부를 그린답니다.

사용 키는 `_state`의 `bin`, 경고별 `level/reason/bbox/extra`, `active_warnings`, `d_front_m/d_left_m/d_right_m`, `f_px/f_calibrated`와 `_ego`, `_corridor`, `_objs`, `vp.y`랍니다. clean 버전은 `bin`, `top_warning`, `top_reason`, `per_obj_zones`도 참조한답니다.

**2. clean HUD 재사용 방식**

`_state` 등 내부 객체를 유지하고 `show_zones=False`이면 코드상 재사용 가능한 구조랍니다. JSON 결과만으로는 부족하답니다. 구역을 켜면 `from __main__ import draw_zones_on_ax`에 의존하며, 실패를 숨겨 구역이 조용히 누락된답니다. `zone_alpha`도 전달하지 않사와요. 문서의 `save=`는 실제 인자인 `save_path=`와 다르답니다.

그대로 채택하기보다 `viz.py`에서 명시적 의존성으로 정리할지 결정이 필요하답니다.

**3. MVP 표시안 승인**

샘플 3장은 모두 1920×1080이랍니다. 이미지별 HUD PNG와 동일 순서의 1행 3열 갤러리를 제안하와요.

- 유지: 등급 배지, 활성 경고, 사유, 경고 박스, 추정 거리, 얇은 차선, 방향별 거리, 차선 측정 불가 표시, 파일명.
- 제외: 큰 자막, 광채, 이모지, 구역 채움, 초점거리 등 디버그 정보, GT 비교.
- 비경고 박스는 회색으로 통일하고, clean 버전의 박스 하단 위치 기반 위험색 추정은 제거하는 안이랍니다. 누락 거리는 `—`, 차선 측정 불가는 등급과 별도로 표시하는 안이랍니다.
