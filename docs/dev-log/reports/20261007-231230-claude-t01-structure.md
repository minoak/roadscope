### 2. 노트북에서 모듈이 이어지는 순서 (`RiskAssessorV5.assess` → `assess_v5`)
0. 이미지를 넣으면 U-Net R34 5-fold가 픽셀마다 다수결로 7-class mask를 만든다. 외부 mask를 직접 넣는 `assess_with_mask`가 기본 경로다. depth는 Depth Pro / DA V2 / None 중 하나로, `(depth_map, focal_px, is_metric)`을 돌려준다.
1. `detect_lane_lines(mask)`: class 3을 Hough 변환한 뒤 군집으로 묶어 lines를 만든다. 이어서 `vp_from_lanes`로 `(vp_x, vp_y, conf)`를 구하는데, conf<0.3이면 VP를 (W/2, 0.4H)로 고정한다. 다음으로 `identify_ego_lane`이 내 차선 좌, 우선을 고르고, 한쪽만 잡히면 반대쪽을 대칭으로 합성한다.
2. `DistanceEstimator`의 f_px를 정한다. Depth Pro의 focal을 먼저 쓰고, 없으면 차선폭으로 역산하고, 그것도 안 되면 W×1.2를 쓴다.
3. `extract_objects`가 class 4/5/6을 연결 성분 단위로 나눠 객체로 만든다. 그다음 `get_ego_mask`(class 5+6 중 화면 하단 중앙에 가장 가까운 덩어리)와 겹치는 Moveable 조각을 버린다.
4. `build_corridor`를 실행한다. 좌, 우 차선이 모두 있고 vp_conf≥0.3일 때만 만든다.
5. 객체마다 `est.estimate`로 거리를, `classify_zone`으로 구역 등급을 붙인다.
6. 화면 가로 위치 cx/W로 방향을 나눈다(정면 0.35~0.65, 그 왼쪽은 좌, 오른쪽은 우). 차선 침범자(strict / x1) 목록도 만든다.
7. ego 마스크의 무게중심 x를 내 위치(ego_cx)로 쓴다.
8. `detect_fcw` / `detect_ldw` / `detect_bsw` / `detect_head`로 4개 경고를 따로 판정한다.
9. zone 보정 2개를 적용한다.
   - FCW가 면적만으로 L3이 됐는데 구역 등급이 2 미만이면 L2로 낮춘다.
   - sidelobe 비율이 0.45를 넘으면 BSW를 L0에서 L2로 올린다.
10. `suppress_short_range_warnings`로 2m 미만 경고를 억제한다(내 바이크를 오인한 것으로 간주). HEAD는 사후검증을 거친다: FCW가 4.5m 이하로 함께 켜져 있지 않으면 끈다.
11. **bin = max(4개 level)** → 안전/주의/위험/치명. 결과는 result dict로, HUD는 `draw_hud_v5`(노트북 자체 HUD) 또는 `hud_v5_clean`으로 그린다.
