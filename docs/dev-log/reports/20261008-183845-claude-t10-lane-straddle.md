## 내가 내린 판단
- 원인은 t07의 픽셀 제거가 아니었다. mixkit의 측정 불가 19건은 전부 노트북 LDW의 편향 30% 초과 가드였다. 편향을 부풀린 건 미러 테두리(216, 240)와 바람막이 테두리(618)가 ego 차선으로 뽑힌 것이라, 선택 검증으로 해결했다.
- 차선 위 주행: 편향이 30%를 넘어도 이탈 쪽 실제 검출선이 원본 마스크의 화면 하단 30%까지 이어져 보이면 L1로 판정한다. L1로 둔 근거: 노트북이 한 프레임 이탈 L2를 오탐 때문에 뺐고, 근거리 픽셀은 그 확신을 일부만 채운다.
- 시간 축 보정: 차선이 끊긴 뒤 0.8초 안에 직전 판정이 L1 이상이거나 편향이 커지던 중이면 L1로 유지한다(L1을 넘지 않음). 기본은 켬.
- VP 허용치는 0.20W다. 0.05W로 하면 커브 바깥 실제 차선(0.05~0.16W)까지 버려서, 대칭 합성선으로 L1 → L0 오판이 13건 생겼다.
