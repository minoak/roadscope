## 내가 내린 판단
- 반복 검출로 실내 물체로 보는 기준:
  - 내 차가 움직이는 프레임의 50% 이상에서 잡힘
  - 그중 70% 이상이 같은 자리, 같은 크기(IoU≥0.5, 면적 ±30%)
  - 좌, 우, 위 테두리에 닿고 폭이 화면의 25% 이하
  - 중심이 앞차 보호 영역(소실점 ±20%W, 수평선 아래) 밖
- 앞차와 구분: 앞차는 보호 영역 안에 있고 크기, 위치가 바뀜. 정지 중 프레임은 세지 않음
- 박스 면적의 50%(되살린 박스는 30%) 이상이 영역 안이면 뺌
- Mask2Former는 5장 과반 투표 후 화면 테두리에 닿는 덩어리만 씀. 광류로 보닛을 못 잡으면 보닛 행도 여기서 정함
- 차선 쌍 맞춤을 30배 빠르게 고침(probe 90장 결과 동일)
